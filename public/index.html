Security Audit

Spade (DNS Inspector)

DNS security inspector. Checks SPF, DMARC, CAA, DNSSEC, MTA-STS, and DKIM in parallel via server-side DNS resolution.

🔒
Enter a domain and click Inspect.
Grading Reference
Check Pass / Warn / Fail conditions Example record
DMARC Pass p=reject
Warn p=quarantine (spam, not rejected)
Fail p=none or no record 		v=DMARC1; p=reject; rua=mailto:dmarc@example.com
SPF Pass ends with -all (hard fail)
Warn ends with ~all (soft fail)
Fail no record, +all, or ?all 		v=spf1 include:_spf.google.com -all
DKIM Pass selector TXT found with v=DKIM1
Warn none of 20 common selectors matched
Fail DNS error querying all selectors 		v=DKIM1; k=rsa; p=MIGfMA0GCS... at selector._domainkey.example.com
MTA-STS Pass TXT record + policy file with mode: enforce
Warn mode: testing or policy unreachable
Fail no TXT record at _mta-sts 		v=STSv1; id=20240101000000 at _mta-sts.example.com
CAA Pass records with issue, issuewild, and iodef
Warn present but missing iodef or issuewild
Fail no records (any CA can issue) 		0 issue "letsencrypt.org"
0 issuewild ";"
0 iodef "mailto:postmaster@example.com"
DNSSEC Pass DS record at registrar + AD bit set
Fail zone unsigned — responses can be forged 		DS record published at registrar; DNSKEY in zone. Enable via DNS provider (e.g. Cloudflare, Route 53).
